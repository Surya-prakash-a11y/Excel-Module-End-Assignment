# E-Commerce Sales Data Analysis

## 📌 Project Overview
This project focuses on analyzing an E-Commerce Sales Dataset using Microsoft Excel. The objective is to clean the data, organize it, and generate meaningful business insights through formulas, PivotTables, charts, and dashboards.

## 🎯 Objectives
- Clean and prepare the dataset
- Analyze sales performance
- Identify top-selling products
- Track customer purchasing trends
- Evaluate the impact of discounts
- Create interactive reports and dashboards

## 📂 Dataset
The dataset contains information related to:
- Order ID
- Order Date
- Customer Name
- Product Name
- Category
- Quantity
- Unit Price
- Discount
- Sales Amount
- Region
- Payment Method

- Microsoft Excel 2021

- Data Validation
- Conditional Formatting

## 📈 Analysis Performed
- Sales by Product
- Sales by Category
- Monthly Sales Analysis
- Regional Sales Performance
- Customer Purchase Analysis
- Discount Analysis
- Revenue Summary

## 📋 Key Insights
- Identified the highest-selling products.
- Compared sales across different regions.
- Analyzed customer buying patterns.
- Measured the effect of discounts on revenue.
- Created summary reports for better decision-making.

This project demonstrates practical Excel skills for data analysis, including data cleaning, reporting, visualization, and business insight generation.
